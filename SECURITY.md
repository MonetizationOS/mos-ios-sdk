# Security

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open this repository's **Security** tab and choose **Report a vulnerability**. Please do not open a public issue or pull request for a security problem.

Include what you found, the SDK version and platform, and steps to reproduce it. We will acknowledge the report and work on a fix.

## Supported versions

Only the latest release gets security fixes. Fixes ship as a new release.

## Scope

This repository holds the MonetizationOS iOS SDK (the Swift package) and its example app. Report a problem in the Android SDK to [MonetizationOS/mos-android-sdk](https://github.com/MonetizationOS/mos-android-sdk). Problems in the MonetizationOS service itself are out of scope here.
