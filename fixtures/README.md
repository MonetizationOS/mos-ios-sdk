# Conformance fixtures

Every SDK test suite loads each file here and asserts the following.

| File | Expectations |
| --- | --- |
| `decision-success.json` | Decodes. `eventId` as given. `identity.isAuthenticated == false`, identifier `mos-anon-v1-abc` is persisted. `features.article.properties.enabled` is meterable with `counterId == "default:feat_article.enabled"`, `hasAccess == true`, `consumedInRequest == true`, `consumedUnitsInRequest == 1`, `uniqueResources == true`, `remainingUnits == 2`. `maxArticles` is number `3`; `tier` is string `"free"` with `isFallback == true`; `adsFree` is boolean with `value == null`; `future` decodes as `unknown` with type `"gauge"` and the decision still decodes. `podcast.enabled` is meterable with `hasAccess == false` and no numeric fields. `surfaceProperties.entitled == false`. Offer-token discovery finds exactly **3** tokens: one with `expirationMsUtc == 1893456000000`, one with `expirationMsUtc == 1577836800000` (in `componentBehaviors.home`), one with `null`; the `not.a.jwt` string is not a token. The cache expiry for this decision stored at `t` with ttl 24h is `min(t + 24h, 1577836800000)`, i.e. already expired at any time after 2020-01-01, so a cache put followed by a get at `now > 1577836800000` returns nothing. Serving this decision from cache for resource `article/999` enqueues exactly one counter update `{ counterId: "default:feat_article.enabled", resourceId: "article/999", update: 1 }`. |
| `decision-success-paywalled.json` | `enabled.hasAccess == false`, `consumedInRequest == false`, `excessUnitsInRequest == 1`. Served from cache it enqueues **nothing**. `componentsSkipped == true`. One token discovered (future). |
| `decision-success-jwt-fallback.json` | Request was a JWT; response `isAuthenticated == false` → `mos-anon-v1-minted` is persisted as the anon id when none is stored; a stored anon id is kept. |
| `decision-success-authenticated.json` | `isAuthenticated == true` → nothing is persisted. `jwtClaims.sub == "user_42"`. `customer.hasProducts == true`, `customerIdentifiers` has 2 entries. `enabled` has `uniqueResources == false`, `consumedUnitsInRequest == 2`; served from cache it enqueues `update: 2`. |
| `decision-success-minimal.json` | Decodes with no `jwtClaims`, empty `surfaceBehavior` (no `properties`), empty features. `surfaceProperties` is an empty object. No tokens. |
| `error-400.json` … `error-531.json` | Each decodes as the error envelope with the matching `statusCode`. `error-429.json` maps to `Failure.rateLimited`; `error-401.json` to `Failure.unauthorized`; the others to `Failure.apiError` with the status code. When delivered with HTTP 200 they are still failures. |
| `redemption-navigate.json` | `redeemed`, action `navigate` with that URL and `properties.plan == "monthly"`. |
| `redemption-custom.json` | `redeemed`, action `custom` with type `"custom:purchase"` and `properties.productId`. |
| `redemption-custom-bare.json` | `redeemed`, action `custom` with type `"custom"` and `properties.productId`. |
| `redemption-none.json` | `redeemed`, action `none`. |
| `redemption-failure.json` | Delivered with HTTP 409, as the server sends it → `declined` with message `"Already redeemed"`, statusCode 409, eventId as given. |
| `counter-update-success.json` | Flush treats this body with HTTP 200 as sent. |
| `offer-tokens.json` | `future` → 1893456000000; `expired` → 1577836800000; `noExpiry` → null (decodes, no expiry); `garbage`, `twoParts`, `badPayload` → not a token (no expiry, no error). |
| `offer-tokens-markup.json` | Scanning each case's `markup` finds exactly its `tokens`, in order. Found are what the web paywall redeems: the first `token` query parameter of each `mos://redeem` URL, percent-decoded with `+` kept, and each non-empty `data-mos-redeem` attribute value (quoted or not). Scheme, host and attribute name match in any ASCII case. Character references (`&amp;`, `&lt;`, `&gt;`, `&quot;`, `&apos;`, `&#…;`, `&#x…;`) are decoded first. A URL or unquoted value ends at whitespace, `"`, `'`, `<`, `>`, `` ` `` or `\`. Offer-token discovery decodes what it finds in every string, so these tokens bound the cache expiry as `token` keys do. |
| `invalid-json.txt` | Delivered with HTTP 502 → `Failure.httpError` with status 502; delivered with HTTP 200 → `Failure.invalidJson`. Either way the cache is served when present and the transport was called exactly once. |
